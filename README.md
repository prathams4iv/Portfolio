# Pratham Srivastava — Professional Developer Portfolio

An ultra-modern, high-impact developer portfolio engineered with **HTML5, modern CSS3, and vanilla JavaScript** (zero dependencies, no build steps required). Built with a refined **"Linear / Vercel"** engineering aesthetic, ready for instant hosting on **GitHub Pages**.

---

## ⚡ What Makes This Version Professional & Standout?

1. **Vercel / Linear Style Cursor Spotlight:** Interactive card glow layers that smoothly track mouse coordinates (`--mouse-x`, `--mouse-y`) across cards and borders.
2. **Hero Engineering Terminal:** A realistic IDE code showcase widget displaying structured developer metadata alongside the profile avatar, live status pill, and interactive typewriter effect.
3. **Collegiate Stats Ribbon:** High-contrast metric cards highlighting key milestones (`1st Year B.Tech CSE`, `3+ Core Projects`, `SIH '24 Hackathon`, `100% Commitment`).
4. **Bento Grid Architecture:** Contemporary asymmetrical bento layout in the About section with location metadata (Jaipur, India • UTC+05:30), academic affiliation, and core philosophy.
5. **Interactive Skill Filter Tabs:** Seamlessly toggle between `All`, `Languages`, `Web Dev`, `Tools`, and `Soft Skills` with dynamic animated percentage meters.
6. **Interactive Project Filter Bar:** Filter cards by `All Projects`, `Web Development`, or `Python & Logic`.
7. **1-Click Copy Email with Floating Toast:** Instant clipboard copying for `prathamsrivastava63@gmail.com` with feedback toast alerts.
8. **Premier Hackathon Showcase Banner:** Elevated gold/amber laurel card for the **Smart India Hackathon (SIH)**.
9. **Cyber Teal Matrix Aesthetic:** Deep futuristic background (`#031419`) with cyan/emerald ambient aura and glowing glass surfaces.
10. **Interactive Palette Switcher:** Live background theme selector in the navbar with 5 presets (*Cyber Teal, Midnight Navy, Obsidian Carbon, Deep Indigo, Slate 900*) and `localStorage` persistence.

## 💻 Running Locally

### Option 1: Python HTTP Server
Open PowerShell in the `portfolio` folder:
```powershell
python -m http.server 8080
```
Then visit:
```
http://localhost:8080
```

### Option 2: Direct File Open
Double-click `index.html` in File Explorer or open with VS Code Live Server.

## 🌐 Deploy to GitHub Pages (Free)

```bash
git init
git add .
git commit -m "Deploy professional developer portfolio"
git branch -M main
git remote add origin https://github.com/prathams4iv/portfolio.git
git push -u origin main
```
Go to **GitHub Repo → Settings → Pages → Deploy from a branch (`main` / root)**.  
Your website is live at: **`https://prathams4iv.github.io/portfolio/`**
